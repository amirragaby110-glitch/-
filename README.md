# 🔺 گرانش فالز — اولتی‌میت نکسوس (Gravity Falls Ultimate Nexus)

> **یک وب‌اپِ کامل و فارسی برای دیوانۀ گرانش فالز** — دانشنامه، موزیک، رازهای تاریک، فکت، داستان، ویدیو، گالری، هوش مصنوعی، صدای شخصیت‌ها، ثبت اطلاعات، آزمون و PWA آفلاین.
> ساخته‌شده با **Next.js 15 + React 19 + TypeScript + Tailwind CSS 4 + Three.js + GSAP + Framer Motion** — آمادهٔ دیپلوی روی **Vercel**.

> ساخته‌شده تا جاذبه ابشار برای ایرانیان سرزمین ام ❤️ — «تابستان هیچ‌وقت تمام نمی‌شود.»

### ➕ قابلیت‌های اضافه‌شده (فراتر از لیست)
- **پالت فرمان سراسری (Ctrl+K)** با BM25 روی تمام دانشنامه
- **ثبت اطلاعات جدید + آپلود تصویر** (`/submit`) در **Dexie/IndexedDB** با فشرده‌سازی خودکار، خروجی/ورودی JSON
- **آزمون گرانش فالز** (`/quiz`) با تایمر و کارنامه و اشتراک نتیجه
- **فکت امروز**، **علاقه‌مندی‌ها**، **نوار پخش چسبان (MiniPlayer)**، **میان‌برها**، **حالت شب خودکار**
- **دسترسی‌پذیری**: RTL کامل، `prefers-reduced-motion`، کنتراست و کلمات کلیدی فارسی در جستجو

## 🚀 شروع سریع

```bash
npm install
npm run dev            # Next 15 + Turbopack → http://localhost:3000
# ساخت پروداکشن:
npm run build && npm start
```

اختیاری — فعال‌سازی هوش مصنوعی واقعی: فایلی به نام `.env.local` بسازید:

```bash
GROQ_API_KEY=gsk_....        # رایگان از console.groq.com
GROQ_MODEL=llama-3.3-70b-versatile
```

بدون کلید، چت با **موتور محلی نکسوس (RAG استخلاصی)** کار می‌کند — کاملاً آفلاین و بدون سرور.

## ☁️ دیپلوی روی Vercel (گام‌به‌گام)

1. ریپو را روی GitHub پوش کنید.
2. به <https://vercel.com/new> بروید → **Import** ریپو. Vercel خودکار Next.js 15 را تشخیص می‌دهد (Node 22).
3. در **Settings → Environment Variables** اضافه کنید:
   - `GROQ_API_KEY` (اختیاری ولی توصیه‌شده)
4. **Deploy** — framework از `vercel.json`؛ کش فونت‌ها/سرویس‌ورکر تنظیم شده است.
5. برای آپدیت خودکار: پوش روی `main` = دیپلوی خودکار (CI در `.github/workflows/ci.yml`؛ برای Workflow Vercel توکن‌های `VERCEL_TOKEN/ORG_ID/PROJECT_ID` لازم است — یا ساده‌تر: همان اتصالِ مستقیم Vercel GitHub را نگه دارید و فایل workflow را پاک کنید).

### نکات مهم دیپلوی
- **PWA/سرویس‌ورکر**: `start_url: /` و کش آفلاینِ صفحات دانشنامه + فونت‌ها؛ ویدیوهای بیرونی طبیعی نیاز به اینترنت دارند.
- **موزیک**: هیچ فایل صوتی کپی‌رایت‌دار در ریپو نیست — موتورِ نکسوس‌سوند همه‌چیز را با Web Audio می‌سازد؛ دانلودها WAVِ رندرشده‌اند. لینک‌های رسمی یوتیوبِ دیزنی embed شده‌اند.
- **ویدیو**: این اپ پلیرِ لینک‌های هواداری/آپاراتی است؛ محتوای کامل سریال را منتشر نمی‌کند (کپی‌رایت دیزنی). «دانلود ویدیو» برای فایل‌های محلی/لینک‌های مجازِ خودتان است.
- **داده‌های کاربر**: همۀ ثبت‌ها (فکت/عکس/داستان) **فقط در مرورگرِ کاربر** (IndexedDB) می‌ماند؛ برای اشتراک «خروجی JSON» را بفرستید تا در `src/data` کامیت کنیم.

## 🎨 تکنولوژی‌ها

Next.js 15 (App Router، `allowedDevOrigins`، رندر استاتیک) · React 19 · TypeScript 5.6 (strict) · Tailwind CSS 4 (@theme، dark-variant سفارشی) · Three.js 0.169 (شفدرهای سفارشی) · Framer Motion 12 · GSAP 3.12 · Zustand 5 (persist) · Dexie 4 (IndexedDB) · Web Audio API (آفلاین‌رندر + آنالایزر) · Web Speech API (TTS) · View Transitions API · PWA (SW + manifest) · Vercel Edge-ready Node route.

## 🛠 راهنمای توسعه

- افزودن فکت: به `src/data/fun.ts` / `horror.ts` آیتم اضافه کنید (id یکتا) — بیلد و تمام.
- افزودن آهنگ: در `tracks.ts` یک «ملودی‌گراف» (پروگرسیون + موتیف + سبک) بسازید؛ موتور خودش تنظیم کامل می‌چیند.
- تغییر صداها: `src/lib/tts.ts` → `VOICE_PRESETS`.
- تست AI محلی: `curl -X POST localhost:3000/api/chat -H 'content-type: application/json' -d '{"messages":[{"role":"user","content":"بیل کیست؟"}]}'`
